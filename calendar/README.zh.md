# calendar.nvim

[English](README.md) | **中文**

终端 **月历浮窗**：公历日期、当前时间、农历、节气/传统节日与公历节日；支持换月换年、日期备注与颜色标记。

## 依赖

| 组件 | 说明 |
|------|------|
| Neovim 0.9+ | **纯 Lua**，无 Python / 网络依赖 |

农历数据覆盖 **1900–2100**。备注与颜色保存在 `stdpath("data")/calendar-nvim-notes.json`。

## 安装

```vim
Plug '/path/to/nvimplugins/calendar'
" 或整仓 nvimplugins（默认包含 calendar）
```

```lua
-- lazy.nvim 整仓
{ "cfwang123/nvimplugins", lazy = false }
```

## 快速上手

1. **`<leader>cal`** 或 **`:Calendar`** 打开月历浮窗  
2. **`h` / `l`** 换日，**`j` / `k`** 换周；**`[` / `]`** 换月，**`{` / `}`** 换年  
3. **`t`** 回到今天；**`n`** 编辑选中日备注；**`c`** 循环颜色标记；**`x`** 清除备注与标记  
4. **`L`** 切换中/英文界面；**`q`** 关闭  

格子内第二行显示农历短标签（初一显示「正月」等），遇节日/节气时优先显示节日名。

**备注指示**：有备注的日期在农历/节日标签后显示红色 **`●`**（选中该日时为蓝底浅红）。用 **`n`** 编辑备注后自动出现；**`x`** 清除备注后消失。

## 命令

| 命令 | 说明 |
|------|------|
| **`:Calendar`** | 打开月历浮窗 |
| **`:CalendarClose`** | 关闭浮窗 |

## 默认快捷键

| 键 | 作用 |
|----|------|
| **`<leader>cal`** | 打开月历 |
| **`h` `l`** / **← →** | 前/后一天 |
| **`k` `j`** / **↑ ↓** | 前/后一周 |
| **`[` `]`** 或 **`<` `>`** | 上/下月 |
| **`{` `}`** | 上/下年 |
| **`t`** | 今天 |
| **`n`** | 备注（`vim.ui.input`） |
| **`c`** | 颜色标记循环（红/橙/黄/绿/蓝/紫/粉） |
| **`x`** | 清除当日备注与标记 |
| **`L`** | 中英文 |
| **`q` / `Esc`** | 关闭 |
| **鼠标左键** | 点击选中日期（需 `mouse` 支持） |

## 配置

```lua
require("calendar").setup({
  ui_lang = "auto",       -- "auto" | "zh" | "en"
  border = "rounded",
  keys_open = "<leader>cal", -- false 关闭默认快捷键
  clock_ms = 1000,        -- 标题栏时钟刷新；0 关闭
})
```

## 说明

- **节假日**：内置公历节日、农历传统节日（春节/端午/中秋等）与二十四节气近似日期；不含法定调休/补班数据。  
- **颜色优先级**：选中日（整格蓝底）> 自定义颜色标记（数字）> 今天高亮 > 周末/节日红字；备注 **`●`** 始终为红色强调。  
- 高亮按 UTF-8 字节偏移绘制，中文农历行与选中格对齐。  
- 语言偏好写入 `stdpath("data")/calendar-nvim-prefs.json`。
